VTLOG Live Driver PiP Bookmarklet v1.2.0

Opens a Picture-in-Picture window showing your live VTLOG job data.

1. Configure

  1. Enter your VTLOG profile link:
    Enter a valid VTLOG profile URL or Steam ID64.
  2. Enter your VTC logo image URL (optional):
    Any direct image URL. Leave blank to hide the VTC logo.
  3. Pick a background color:
    #121212
  4. Set background opacity:
    0.8

2. Install

  1. Make sure your bookmarks bar is visible (Ctrl+Shift+B).
  2. Drag this button link to your bookmarks bar:
    VTLOG Live PiP

Usage

  1. Navigate to your VTLOG company live drivers page.
  2. Click the VTLOG Live PiP bookmark.
  3. A 1024×75 floating PiP window appears with your driver row.
  4. Live data syncs every 100ms. Close the PiP window to stop.
  5. Rebuild and re-drag the bookmark if you change Steam ID, logo, or colors.
Requirements:
• Chrome 116+ with Document Picture-in-Picture API.
• VTLOG account profile link or Steam ID.
