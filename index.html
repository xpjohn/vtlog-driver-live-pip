VTLOG Live Driver PiP Bookmarklet v1.0.3

Opens a Picture-in-Picture window showing your live VTLOG job data.

Install

  1. Enter your VTLOG profile link:
  2. Pick a background color:
    #121212
  3. Make sure your bookmarks bar is visible (Ctrl+Shift+B).
  4. Drag this button link to your bookmarks bar:
    5. VTLOG Live PiP

Usage

  1. Navigate to your VTLOG company live drivers page.
  2. Click the VTLOG Live PiP bookmark.
  3. A 1024×75 floating PiP window appears with your driver row.
  4. Live data syncs every second. Close the PiP window to stop.
  5. Repeat the process if there's a version update and Steam ID or background color change.
Requirements:
• Chrome 116+ with Document Picture-in-Picture API.
• VTLOG account profile link or Steam ID.
